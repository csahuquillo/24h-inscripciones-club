# Assets del club (no incluidos en el repo)

Coloca aquí los ficheros de tu club (la app los detecta solos):

- `logo.png` / `logo.jpg` / `logo.svg` — logo de la cabecera.
- `membrete.png` — banda superior (opcional).
- `lona_1.jpg`, `lona_2.jpg`, `lona_3.jpg` — patrocinadores en el pie de la home (opcional).

Si no existen, la web usa el nombre del club como texto y omite las bandas.
